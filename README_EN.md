### <img src="./ophel/assets/logo.png" height="24" alt="Ophel Logo"> [Ophel](./ophel/README.md)

<p align="center">
  <strong>✨ AI's Benefit, Within Reach ✨</strong><br/>
</p>

👋 **Ophel** is the successor to `gemini-helper`, completely rewritten with a modern tech stack. It is available as both a **Browser Extension** and a **Userscript**, designed to enhance your AI experience across **Gemini**, **ChatGPT**, **Claude**, **Grok**, and **AI Studio**.

[👉 View Source Code and Documentation on GitHub](https://github.com/urzeye/ophel)

> [!TIP]
> **Gemini Helper**: Session management & export, conversation outline, prompt management, tab enhancements (status/privacy/notify), reading history & restore, bi-directional/manual anchors, watermark removal, bold fix, formula/table copy, model lock, page beautification, theme switching, smart dark mode (standard/enterprise).

**Key Features**:

- ✅ Session Management (📁 Folders / 🏷️ Tags / 🔍 Search / 📤 Export / 📌 Batch Ops)
- ✅ Conversation Outline (Auto H1-H6 Headers, Scroll/Jump/Fold/Search/Filter)
- ✅ Prompt Management (Quick Insert, Categories, Search, Drag Sort)
- ✅ Content Assistant (LaTex Copy / Table Markdown Copy / Banana Watermark Removal / Export)
- ✅ Markdown Bold Fix (Fixes rendering issues in standard version)
- ✅ Tab Enhancements (Status Customization, Privacy Mode, Notifications)
- ✅ Bi-directional Anchors (Navigates like `cd -`)
- ✅ Quick Nav (Top/Bottom, Collapsible Buttons)
- ✅ Reading History (Auto-save/Restore position)
- ✅ Widescreen (px/%, adaptation for Shadow DOM)
- ✅ Model Lock (Global support, auto-switch)
- ✅ Theme Switching (Smart Dark Mode, System Sync)
- ✅ Settings Panel (Customizations)
- ✅ Multi-site Support (Standard / Enterprise)

### [Jianguoyun WebDAV Password Manager](./jianguoyun-webdav/README.md)

Restore hidden WebDAV third-party app password management in Jianguoyun web app without desktop client.

<img width="3795" height="1871" alt="image" src="https://github.com/user-attachments/assets/135af64d-29e2-425a-a7f3-eaf5fe347cf0" />

**Key Features**:
- ✅ Restore full app passwords management table (app name, authorization date, show/hide password, revoke authorization)
- ✅ Clean web ads (hide sidebar "App Recommendation" item and floating carousel promo card)
- ✅ One-click copy for WebDAV server URL, account email, and app passwords
- ✅ Generate new app passwords directly from the web interface with automatic copying
- ✅ Safe revocation with custom elegant confirmation dialog
- ✅ Smooth SPA auto-mounting and zero external dependencies
