## ✨ Возможности

### 📝 Управление промптами

- **Быстрая вставка**: Вставка часто используемых промптов в чат одним кликом
- **Управление категориями**: Фильтрация, переименование и удаление категорий
- **Функция поиска**: Быстрый поиск нужных промптов
- **CRUD-операции**: Настройка и управление библиотекой промптов
- **Функция копирования**: Копирование содержимого промпта в буфер обмена одним кликом
- **Перетаскивание и сортировка**: Свободная настройка порядка отображения промптов

### 📁 Управление диалогами

- **Архив папок**: Создание пользовательских папок для организации истории чата
- **Многоцветные теги**: Более 30 традиционных китайских цветов, поддержка пользовательских цветов и управления несколькими тегами
- **Поиск в реальном времени**: Быстрая фильтрация по заголовку, поддержка комбинированной фильтрации по тегам
- **Пакетные операции**: Множественный выбор для пакетного удаления, перемещения и архивирования
- **Экспорт диалога**: Экспорт в формат Markdown/JSON/TXT, изображения можно конвертировать в Base64
- **Бесшовная синхронизация**: Автоматическая синхронизация последних данных из боковой панели Gemini (совместимо со Standard/Enterprise)

### 📑 Навигация по структуре

- **Автоматическое извлечение**: Извлечение структуры заголовков из ответов ИИ (поддержка Standard и Enterprise Shadow DOM)
- **Группировка запросов пользователя**: Группировка структуры по очередности диалога, запросы пользователя как заголовки групп (значок 💬)
- **Умный отступ**: Автоматическая настройка отступа на основе высшего уровня для уменьшения пустого пространства слева
- **Быстрый переход**: Клик по элементу структуры для плавной прокрутки и подсветки на 2 секунды
- **Синхронная прокрутка**: Автоматическая подсветка соответствующего элемента структуры при прокрутке страницы (переключается в настройках)
- **Фильтр уровней**: Настройка отображения уровней заголовков, Уровень 0 для быстрого сворачивания только до запросов пользователя
- **Управление переключением**: Автоматическое скрытие вкладки структуры при отключении

### 🚀 Быстрая навигация

- **Переход вверх/вниз**: Быстрое позиционирование в длинных диалогах
- **Группа плавающих кнопок**: Доступна даже когда панель свёрнута

### 📐 Ширина страницы

- **Пользовательская ширина**: Поддержка единиц пикселей (px) и процентов (%)
- **Мгновенное применение**: Немедленное применение после настройки, обновление не требуется
- **Независимая конфигурация**: Разные настройки для разных сайтов

### ⚓ Умная система позиционирования

Две независимые системы записи позиции:

- **История чтения (Reading Progress)**:
  - Долгосрочная "память о прогрессе чтения", поддерживает восстановление между обновлениями/сессиями
  - Автоматическая запись при прокрутке, сохранение в GM_storage
  - Автоматическое восстановление при загрузке страницы или смене диалога

- **Двунаправленный якорь**:
  - Краткосрочная "точка возврата", аналогично кнопке назад в браузере или `git switch -`
  - Автоматическое сохранение текущей позиции при клике на кнопки структура/верх/низ
  - Поддержка переключения туда-обратно между двумя позициями

### 🏷️ Улучшения вкладок

- **Отображение статуса генерации**: Автоматическое отображение значка ⏳ (генерация) или ✅ (завершено) в заголовке вкладки
- **Пользовательский формат заголовка**: Поддержка комбинаций плейсхолдеров `{status}{title}[{model}]`
- **Режим конфиденциальности (Кнопка босса)**: Маскировка заголовка вкладки одним кликом как "Google", скрытие содержимого диалога
- **Уведомление о завершении**: Отправка уведомления на рабочий стол при завершении фоновой генерации
- **Автофокус окна**: Автоматический вывод окна браузера на передний план при завершении генерации

### ⚙️ Панель настроек

- **Переключение вкладок**: Три вкладки - Промпты, Структура, Настройки
- **Настройки панели**: Настройка развёрнутого/свёрнутого состояния по умолчанию, автоматическое скрытие при клике снаружи
- **Исправление китайского ввода**: Опциональный переключатель для исправления проблемы первого символа в Enterprise
- **Смена языка**: Поддержка упрощённого китайского/традиционного китайского/английского

### 🎯 Умная адаптация

- ✅ Gemini Standard (gemini.google.com)
- ✅ Gemini Enterprise (business.gemini.google)

### 🌓 Автоматический тёмный режим

- **Умное обнаружение**: Отслеживание в реальном времени переключения светлого/тёмного режима системы/страницы
- **Полная адаптация**: Тщательно настроенная цветовая схема тёмной темы, комфортная для глаз

### 📋 Помощь с контентом

- **Копирование формулы двойным кликом**: Двойной клик по математической формуле для копирования LaTeX-источника, автоматическое добавление разделителей
- **Копирование таблицы в Markdown**: Добавление кнопки копирования в верхнем правом углу таблицы, прямое копирование в формате Markdown
- **Удаление водяного знака**: Автоматическое удаление водяного знака NanoBanana с изображений, сгенерированных Gemini AI
- **Привязка к краю**: Автоматическое скрытие при перетаскивании панели к краю экрана, отображение при наведении
- **Ручной якорь**: Установка/возврат/очистка позиции якоря с помощью быстрой панели инструментов

## 🔧 Использование

1. Установить расширение браузера Tampermonkey
2. Установить этот скрипт
3. Открыть страницу Gemini, панель управления промптами появится справа
4. Кликнуть на промпт для быстрой вставки

## ⌨️ Быстрые операции

| Операция | Описание |
| --- | --- |
| Клик по промпту | Вставить в поле ввода |
| 📋 Кнопка копирования | Копировать содержимое промпта |
| ☰ Ручка перетаскивания | Перетащить для изменения порядка |
| ✏ Кнопка редактирования | Редактировать промпт |
| 🗑 Кнопка удаления | Удалить промпт |
| ⚙ Управление категориями | Переименовать/удалить категорию |
| Клик по кнопке × | Очистить вставленный контент |
| Enter для отправки | Автоматически скрыть плавающую панель |
| Кнопки ⬆ / ⬇ | Перейти к началу/концу страницы |
